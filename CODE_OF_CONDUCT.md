# Code de conduite

## Notre engagement

Nous voulons que la participation à ce projet soit une expérience agréable et respectueuse pour tout le monde, quels que soient l'âge, le genre, l'origine, le niveau d'expérience ou les opinions de chacun.

## Comportements attendus

- Faire preuve de courtoisie et de respect envers les autres contributeurs.
- Accepter les critiques constructives avec ouverture.
- Se concentrer sur ce qui est le mieux pour le projet.

## Comportements inacceptables

- Les propos injurieux, discriminatoires ou harcelants.
- Les attaques personnelles ou politiques.
- La publication d'informations privées d'autrui sans son accord.
- Tout autre comportement qui serait jugé inapproprié dans un cadre professionnel.

## Application

Les responsables du projet peuvent modifier ou supprimer les commentaires, tickets et contributions qui ne respectent pas ce code de conduite, et exclure temporairement ou définitivement leurs auteurs.

## Signaler un comportement

Pour signaler un comportement inacceptable, contacter le responsable du projet via son profil GitHub : [princeobenga242-star](https://github.com/princeobenga242-star).
